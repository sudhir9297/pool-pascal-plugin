# Security policy

## Supported versions

Only the latest published version receives security fixes while the package is below version 1.0.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for `pascalorg/plugin-pool` and include:

- the affected version;
- a minimal reproduction;
- the expected impact;
- any known workaround.

The maintainers will confirm receipt, assess severity, and coordinate a fix before public disclosure.
